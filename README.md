# My-Cool-Alarm-Clock
----------------------------------------------------------------------------------
This is a 4 key alarm clock that is run by a XIAO ESP32 module, and TFT Screen display . 
-------------------------------------------------------------------------------------
Core feature 

1.A custom ringtone
2.A custom PCB
3.A custom 3D case
4.4 clicky buttons

--------------------------------------------------------------------------------
How to run
--------------------------------------------------------------------------------
Download the latest version of arduino IDE

Follow the first few steps of the Software Preperation guide in the docs here on how to install the ESP 32 board in Arduino IDE

Install the following libraries:

    Adafruit_ST7735 and ST7789
    Adafruit_GFX

then connect the esp32 with pc and click this tick mark button on top left.
-------------------------------------------------------------------------------
BOM:

    Seeed XIAO ESP32C3 -1
    MX-Style Keyboard Switches -4
    2.25in TFT Screen -1
    3.3V Piezo Buzzer -1
    White Blank DSA Keycaps -1
    2.54mm 8 Pin Male Header -1
    20cm Female-Female Jumper Wires -8
    M3x5x4 Heatset Inserts -8
    M3x8mm Screws -4
    M3x16mm Screws -4
